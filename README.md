# CMP NeoPixel Sign

This was a basic circuit playground express project that invovled cutting up a neopixel RGBW strip up into 16 separate 16 pixel strips and then soldering them back together on a grid. There were then several demo files created to show different functionality on the grid. 
There is a mario pixel art, a rainbow used for verifying all pixels were working (I was learning to solder here too), and an animation that could be used for vistors/tours.
